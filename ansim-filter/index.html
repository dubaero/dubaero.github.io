1. 파일 넣기

아래에 파일을 끌어다 놓거나 눌러서 고르세요. PDF·워드·엑셀 그대로 넣으면 됩니다.

파일을 끌어다 놓거나 눌러서 고르세요 한글 .hwpx · PDF .pdf · 엑셀 .xlsx .xls · 워드 .docx · 텍스트 .txt .csv · 웹문서 .html · 사진 .png .jpg

붙여넣기로 하기 (복사한 글자를 바로 가리기)

형식마다 받는 모습

  • 한글 .hwpx — 서식·표 그대로, 글자만 바꿔서 .hwpx로 내려받습니다. 공공기관 문서는 이 형식으로 넣어 주세요.
  • PDF .pdf — 글자만 뽑아 가린 뒤 .txt로 내려받습니다. PDF의 원래 모양 그대로 되살리는 일은 브라우저만으로는 안전하게 할 수 없어 글자만 남겨 드립니다.
  • 엑셀 .xlsx · 워드 .docx — 서식 그대로, 글자만 바꿔서 같은 형식으로 내려받습니다.
  • 텍스트 .txt .csv · 웹문서 .html — 글자 표는 '이름' 열까지 가리고, 웹문서는 서식 그대로 .html로 내려받습니다.
  • 사진 .png .jpg — 사진 속 글자를 읽어(글자 인식) 가린 .txt로 내려받습니다. 사진 자체의 글자를 지우지는 못합니다.
  • 구형 한글 .hwp — 브라우저가 이 형식을 열 수 없습니다. 한글에서 다른 이름으로 저장 → .hwpx(또는 .pdf)로 저장해 넣어 주세요. 서식 그대로 가려집니다.
  • 파워포인트 .pptx — 아직 지원하지 않습니다. 슬라이드는 PDF로 저장해서 넣어 주세요.
  • 음성 .mp3 .m4a .wav — 브라우저만으로는 서버 없이 음성을 글자로 바꿀 수 없어 지원하지 않습니다. 녹음 내용을 글로 옮겨 붙여넣어 주세요.
