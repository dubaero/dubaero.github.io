1. 파일 넣기

아래에 파일을 끌어다 놓거나 눌러서 고르세요.

파일을 끌어다 놓거나 눌러서 고르세요 텍스트 .txt .csv · 워드 .docx · 엑셀 .xlsx .xls · 이미지 .png .jpg

붙여넣기로 하기 (복사한 글자를 바로 가리기)

지원하지 않는 파일과 그 이유

  • 음성 파일(.mp3 .m4a .wav) — 브라우저만으로는 서버 없이 음성을 글자로 바꿀 수 없어 지원하지 않습니다. 녹음 내용을 글로 옮겨 붙여넣어 주세요.
  • 한글 파일(.hwp .hwpx) — 브라우저에서는 한글 문서를 열 수 없습니다. 한글에서 다른 이름으로 저장 → .docx로 저장하거나, 내용을 복사해 붙여넣어 주세요.
  • PDF — 지금은 지원하지 않습니다. 글자를 복사해 붙여넣어 주세요.
  • 이미지 속 글자 — 사진에서는 글자만 읽어 와 새 텍스트 파일로 만들어 줍니다. 사진 자체의 글자를 지우지는 못합니다.
