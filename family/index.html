            A클로바노트 지금부터 녹음할 때
            
      
            1. 휴대폰에 네이버 클로바노트 앱 설치 → 네이버 로그인
            2. 회의 시작 전 가운데 [녹음] → 참석 인원 선택 (말한 사람 구분용)
            3. 회의가 끝나면 [녹음 종료] → 1~3분 기다리면 글로 바뀌어요
            4. '참석자 1, 2'를 이름 대신 역할(팀장·담당자)로 바꾸기
            5. [공유] → 텍스트 복사 → 서식 화면의 [ChatGPT 열기]나 [Claude 열기]
            6. 서식 파일 첨부 → 프롬프트 붙여넣기 → 맨 아래 [받아쓴 글]에 붙여넣기 → 전송
            
      
            성공: 서식 순서대로 나오고 녹음에 없던 내용은 [확인 필요]
            
      
            주의: '데이터 제공 동의'(600분)는 녹음이 서비스 개선에 쓰일 수 있다는 뜻 → 상담·사례 녹음엔 켜지 마세요
            
    
            B노트북LM 정확성이 중요할 때 (무료)
            
      
            1. notebooklm.google.com → 구글 로그인 → [새 노트북]
            2. [소스 추가] → 우리 서식 파일 (PDF·워드, 한글은 변환해서)
            3. 다시 [소스 추가] → 녹음 파일 → 글로 바뀔 때까지 기다리기
            4. 왼쪽 소스에서 녹음을 눌러 받아쓴 글의 이름·날짜·숫자 확인
            5. 채팅창에 서식 화면의 프롬프트 붙여넣기 → 전송
            6. 답변의 출처 번호를 눌러 결정사항이 실제 녹음에 있는지 확인 → 복사해 우리 서식에
            
      
            성공: 문장마다 출처 번호가 붙어 있고, 누르면 녹음 원문이 보여요
            
      
            주의: 구글 드라이브에 있는 녹음은 바로 못 가져와요 → 내 컴퓨터로 내려받아 올리기
            
    
            C제미나이 짧은 녹음 (10분 안팎)
            
      
            1. gemini.google.com 또는 제미나이 앱 → 로그인
            2. 입력창 [+] → 우리 서식 파일 첨부
            3. 다시 [+] → 녹음 파일 첨부
            4. 서식 화면에서 '녹음이 있어요' 프롬프트 복사 → 붙여넣기 → 전송
            5. 받아쓴 글 확인 후 "작성해 줘"
            
      
            성공: 받아쓴 글이 먼저 나오고, 안 들린 곳은 [불명확]
            
      
            주의: 길면 잘리거나 첨부가 안 돼요 → 클로바노트나 노트북LM으로
            
    
            DChatGPT 유료 사용자, 긴 녹음
            
      
            1. 서식 화면에서 [ChatGPT 열기] (프롬프트가 미리 들어가요)
            2. 입력창 [+] → 우리 서식 파일 + 녹음 파일 첨부
            3. 전송 → 받아쓴 글 확인 → "작성해 줘"
            4. "워드 파일로 줘" → 받아서 우리 서식과 비교
            
      
            성공: 서식과 같은 칸의 워드 파일이 나와요
            
      
            주의: 무료 계정은 녹음 첨부가 안 돼요. 아주 긴 파일은 나눠서 올리세요
            
  
            
  
            Claude를 쓰고 싶다면
            Claude는 유료여도 녹음 파일을 글로 바꾸는 기능이 없어요. (마이크로 말하기와 녹음 파일 변환은 다른 기능이에요) A·B로 먼저 글로 바꾼 뒤 Claude에 서식 첨부 + 프롬프트 + 받아쓴 글을 붙여 넣으세요.
